# KVI 밸류에이션 워크벤치 — 공개 배포(예시)

공개 자료(DART 전자공시·한국은행 ECOS)와 정한 규칙으로 **한국 상장사 주식가치 초안을 자동으로 만들고**, 사람이 판단할 곳을
**주당 영향이 큰 순서**로 보여 준 뒤, 사람이 **확정**하면 수식이 살아 있는 엑셀 모델과 보고서 초안을 내려받는 작업 도구입니다
(자동 초안 → 판단 목록 → 확정).

- 앱: https://korea-valuation-insights-nadjarrtmvgmg7kxs9ujyy.streamlit.app/ — 한동안 방문이 없으면 앱이 잠들어, 첫 접속 때 깨우는 데 시간이 걸릴 수 있다
- 작성자: GitHub [Mevius-Skyblue](https://github.com/Mevius-Skyblue) · 라이선스: 코드 [MIT](LICENSE)
- 이용 안내: [USAGE.md](USAGE.md) · 데이터 안내: [DATA_NOTICE.md](DATA_NOTICE.md) · 외부평가 의견서 집계 방법론: [METHODOLOGY.md](METHODOLOGY.md)

## 쓰는 법
1. 회사를 고르고 **평가 시작** → 자동 초안(재무·피어·할인율·DCF·상대가치)과 판단 목록이 만들어집니다
2. 판단 목록에서 후보 값을 고르거나(버튼마다 '지금 주당 → 반영 뒤 주당') 직접 입력하거나 그대로 유지합니다
3. 주가·20일 VWAP을 직접 넣고 **확정** → 엑셀 모델(수식 살아 있음, 엔진 값과 대조)·보고서 초안(.docx)을 내려받습니다

## 데이터 출처와 공개 범위
- 재무·공시: DART 전자공시(숫자마다 접수번호 링크). 금리: 한국은행 ECOS
- **한국거래소 시세는 이 저장소와 앱에 없습니다.** 대상 회사 종가·VWAP(그리고 상장 종속회사·우선주 종가)은 사용하는 사람이 넣고, 그 값의 책임은 입력한 사람에게 있습니다
- 피어는 이름·포함 여부와 집계값(무부채 베타 중앙값·배수 사분위·목표 D/E)만 담았습니다(피어별 시가총액·배수·회귀 값 없음)
- 집계값은 포함 피어(또는 D/E 시점)가 5개 이상일 때만 보여 줍니다. 그보다 적으면 사분위·중앙값으로 피어 값 하나하나를 되짚을 수 있어 '피어 부족(공개 모드)'으로 표시하고, 베타는 시장 평균 1.0·D/E는 0으로 둡니다(직접 입력 가능). 경영권 프리미엄 구간 표 칸은 10건 이상일 때만 분위수를 보여 줍니다
- 회사 범위: 개발·검증에 이미 쓴 190곳(평가 가능 158곳 + 자동 평가 범위 밖 32곳). 다른 회사는 PC 모드에서 초안을 만듭니다
- 경영권 프리미엄은 집계(건수·분위수·구간 표)만 담았습니다(거래별 값·거래 이름·거래별 기준 주가 없음). 시총 백분위는 기준일 값 고정(소수 첫째 자리), 블록 1주당 가격은 사용자가 20일 VWAP을 넣을 때만 계산합니다
- 회사별 공개 스냅샷: `app/public/snapshots/` (DART·ECOS 자료와 집계값, gzip JSON). 세션은 브라우저별 임시 공간에만 있고 세션 파일로 내려받아 이어 씁니다

## 실행
Python 3.13에서 시험했다(새 가상환경에 `requirements.txt`만 설치해 모든 화면 기동 확인).
```
python -m venv venv
venv\Scripts\activate            (macOS·Linux: source venv/bin/activate)
pip install -r requirements.txt
streamlit run app/Home.py
```

## 면책
투자 권유가 아닙니다. 공개 자료와 정한 규칙으로 계산한 가정 하의 추정 내재가치(예시)이며 특정 종목의 가치·가격에 대한 의견이 아닙니다. 금융투자업(투자자문·투자일임) 등록·신고를 하지 않은 개인 학습·포트폴리오 프로젝트입니다. 정확성을 보증하지 않습니다.
